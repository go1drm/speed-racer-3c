# 自由钩索 (Free Grapple) 设计文档

## 概述

自由钩索是一个独立于原版 GrappleHook 的技能系统。玩家按空格射出钩索，钩索飞向前方虚拟锚点并挂住，随后绳索不断收缩将赛车拉向锚点，靠近后绳子断裂将赛车沿当前速度方向甩出，玩家在空中调整车头朝向后再按空格可沿车头方向发射冲刺。发射后如果还有充能，可以立刻接续下一次钩索（无需落地）。

与原 GrappleHook **互斥**，开启自由钩索后原钩索不生效。

---

## 状态机

```
IDLE → PULLING → FALLING → LAUNCHING → FALLING(锁定) → IDLE
                    ↓                       ↓
               WALL_HIT                 WALL_HIT
                                            ↓ (有充能)
                                        PULLING (空中接续)
```

| 状态 | 描述 |
|------|------|
| **IDLE** | 空闲。有充能时按空格触发射出 |
| **PULLING** | 绳索收缩中。分两阶段：①射出飞行（绳松弛甩动）②挂住收绳（绳笔直） |
| **FALLING (未发射)** | 绳断甩出后。空中可调整车头朝向，可按空格发射 |
| **LAUNCHING** | 发射冲刺中。沿车头方向加速 |
| **FALLING (已发射)** | 发射后。车头锁定，有充能可按空格接续新钩索 |
| **WALL_HIT** | 撞墙中断。立即回到 IDLE |

---

## 完整流程

1. **按空格 (IDLE/已发射FALLING + 有充能)** → 消耗 1 层充能
2. **射出动画** → 钩索从车身射出，绳头飞向锚点（ease-out 曲线），绳子松弛剧烈甩动
3. **挂住** → 绳头到达锚点（`rope_taut_delay - 0.1` 秒），0.1 秒内绳子从松弛过渡到笔直
4. **收绳 (PULLING)** → 绳索每帧缩短，车超出绳长时被约束（切线投影+拉力），绳子保持笔直
5. **断绳** → 车与锚点距离 < 绳长 × `arrive_ratio`，或收绳超时
6. **甩出** → 沿当前速度方向甩出，进入 FALLING，镜头震屏+FOV冲击
7. **FALLING (未发射)** → 空气阻力减速，方向键自由调整车头
8. **按空格 (FALLING 未发射)** → 沿车头方向发射，镜头震屏+FOV冲击
9. **LAUNCHING** → 短暂无重力滞空
10. **FALLING (已发射)** → 车头**锁定不可转向**，空气阻力+重力下落
11. **按空格 (已发射 + 有充能)** → 接续新钩索（回到步骤 1）
12. **着地** → 回 IDLE

## 按键

| 按键 | 条件 | 效果 |
|------|------|------|
| 空格 | IDLE + 有充能 | 射出钩索 |
| 空格 | FALLING + **未发射** | 沿车头方向发射 |
| 空格 | FALLING + **已发射** + 有充能 | 接续下一次钩索（空中连续） |
| 空格 | FALLING + **已发射** + 无充能 | 无效 |
| 方向键 | FALLING + **未发射** | 调整车头朝向 |
| 漂移键+方向键 | FALLING + **未发射** | 加速转向 |
| 方向键 | FALLING + **已发射** | ❌ 无效（车头锁定） |

## 参数列表

### 开关

| 变量 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `free_grapple_enabled` | bool | `true` | - | 自由钩索总开关。与原钩索互斥 |

### 锚点

| 变量 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `anchor_offset` | Vector3 | `(0, 5, 15)` | - | 锚点基础偏移。X=右, Y=上, Z=前方基础距离 |
| `anchor_speed_scale` | float | `0.8` | 0~3 | 前方距离随水平速度增加的系数 |
| `anchor_height_speed_scale` | float | `0.15` | 0~1 | 高度随水平速度增加的系数 |
| `anchor_height_upspeed_scale` | float | `0.5` | 0~2 | 高度随向上速度增加的系数 |

**锚点位置公式：**
```
水平速度 = √(vel.x² + vel.z²)
向上速度 = max(vel.y, 0)

前方距离 = anchor_offset.z + 水平速度 × anchor_speed_scale
高度     = anchor_offset.y + 水平速度 × anchor_height_speed_scale + 向上速度 × anchor_height_upspeed_scale
```

举例（水平速度 30 m/s，向上速度 10 m/s）：
- 前方距离 = 15 + 30×0.8 = 39 米
- 高度 = 5 + 30×0.15 + 10×0.5 = 14.5 米

### 收绳

| 变量 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `rope_taut_delay` | float | `0.5` | 0.2~2 秒 | 射出动画时长。绳头飞向锚点的时间 |
| `reel_speed` | float | `35.0` | 5~80 m/s | 收绳速度。每秒绳长缩短多少米 |
| `pull_force` | float | `180.0` | 30~500 N×mass | 绳子绷紧时朝锚点的拉力 |
| `pull_max_time` | float | `2.5` | 0.5~5 秒 | 收绳最大时长。超时强制断绳 |
| `arrive_ratio` | float | `0.2` | 0.05~0.5 | 断绳距离百分比。距离 < 初始绳长 × 此值时断绳 |
| `pull_gravity_cancel` | float | `0.8` | 0~1 | 收绳时重力抵消比例 |
| `collision_exempt_time` | float | `0.3` | 0~2 秒 | 碰撞豁免时间（当前未启用） |

**断绳距离公式：**
```
断绳距离 = 初始绳长 × arrive_ratio
```

**收绳约束逻辑（方案C）：**
- 每帧允许绳长缩短 `reel_speed × delta`
- 车与锚点距离 > 当前允许绳长时：去掉远离锚点的速度分量（切线投影），额外施加朝锚点拉力
- 距离在允许范围内时：施加温和拉力（50% pull_force）
- 拉力方向 Y < 0 时自动钳制为 0（防陷地）

### 甩出

| 变量 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `fling_speed_mult` | float | `1.2` | 1~3 | 甩出速度倍率 |
| `fling_min_speed` | float | `18.0` | 5~40 m/s | 甩出保底速度 |

**甩出速度公式：**
```
甩出速度 = max(当前速度 × fling_speed_mult, fling_min_speed)
甩出方向 = 当前速度方向（Y分量钳制 ≥ -0.2）
```

### 空中

| 变量 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `fall_gravity_mult` | float | `0.5` | 0.1~5 | 空中重力倍率。绳断后统一生效 |
| `air_drag` | float | `0.3` | 0~2 | 空气阻力系数。速度越高减速越猛 |
| `air_turn_speed` | float | `2.5` | 0.5~8 rad/s | 空中转向速度（仅未发射时） |
| `air_drift_turn_mult` | float | `2.0` | 1~5 | 按住漂移键时转向倍率（仅未发射时） |

> ⚠️ 发射后车头**锁定不可转向**。重力和空气阻力对所有空中阶段统一生效。

**空气阻力公式：**
```
F_drag = -速度方向 × 速度 × air_drag × 质量
```

### 发射

| 变量 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `launch_speed` | float | `35.0` | 10~80 m/s | 发射速度 |
| `launch_float_time` | float | `0.4` | 0~1.5 秒 | 发射后无重力时间 |
| `launch_duration` | float | `0.5` | 0.1~2 秒 | 发射持续时间。之后回 FALLING |
| `post_launch_gravity_mult` | float | `2.5` | 1~5 | （保留但未使用，统一用 fall_gravity_mult） |

**发射后行为：**
- 车头方向锁定，不可转向
- 每次飞行只能发射一次
- 发射后有充能可按空格接续新钩索

### 镜头效果

| 变量 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `launch_shake_intensity` | float | `1.2` | 0~3 | 发射时震屏强度 |
| `launch_shake_duration` | float | `0.3` | 0~0.8 秒 | 发射时震屏时长 |
| `launch_fov_boost` | float | `12.0` | 0~30 度 | 发射时 FOV 增量（冲击感） |
| `fling_shake_intensity` | float | `0.6` | 0~3 | 甩出时震屏强度 |
| `fling_fov_boost` | float | `6.0` | 0~20 度 | 甩出时 FOV 增量 |

FOV 冲击自动以 20 度/秒的速度衰减回 0。

### 充能

| 变量 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `max_charges` | int | `3` | 1~5 | 最大充能层数 |
| `charge_per_nitro` | int | `1` | 1~3 | 每次使用氮气获得的充能 |
| `charge_cooldown` | float | `1.0` | 0~5 秒 | 充能冷却时间 |

**充能规则：**
- 启动时满充能
- 使用氮气获得充能
- 飞行中（非 IDLE）不充能
- 撞墙后不再充能直到落地

### 视觉

| 变量 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `rope_color` | Color | `(0.9, 0.75, 0.2, 1)` | - | 钩索线颜色（金麻色） |
| `rope_thickness` | float | `0.12` | 0.02~0.3 米 | 钩索线粗细 |

### 绳索物理（仅视觉）

| 变量 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `rope_node_count` | int | `16` | 8~48 | 绳子节点数 |
| `rope_constraint_iters` | int | `20` | 1~30 | Verlet 约束迭代次数 |
| `rope_gravity` | float | `10.0` | 0~80 | 绳子视觉重力 |
| `rope_damping` | float | `0.08` | 0~0.5 | 绳子阻尼 |

## 绳索视觉动画

| 阶段 | 绳子表现 | 实现 |
|------|---------|------|
| **射出飞行** | 绳头从车飞向锚点，绳子松弛剧烈甩动 | 重力×2.5, 阻尼0.02, 松弛50%, ease-out飞行 |
| **挂住过渡** (0.1秒) | 绳子从松弛快速过渡到笔直 | 回弹力渐增, 重力渐消, 松弛渐缩 |
| **收绳中** | 一根笔直的绳子，随车靠近锚点缩短 | 所有节点强制在直线上 |
| **断绳** | 绳子消失 | `_hide_rope()` |

## 空中接续（连续使用）

弹射后如果还有充能，按空格立刻射出新钩索，无需落地。

```
钩索1 → 甩出 → 弹射 → [有充能] 空格 → 钩索2 → 甩出 → 弹射 → ...
```

理论上充能足够时可以无限连续飞行。充能在 IDLE 时通过使用氮气获得。

## 与 car.gd 的交互

- `car._free_grapple_active`：true 时跳过地面粘附、引擎制动、降低摩擦 90%、禁止漂移/小喷/跳跃
- 输入路由优先级：
  1. IDLE + 有充能 → 射出钩索
  2. FALLING + 已发射 + 有充能 → 接续新钩索
  3. FALLING + 未发射 → 弹射
  4. 其他非 IDLE 状态 → 消费空格（防误触）
- 震屏：通过 car 的 `camera_shake_requested` 信号
- FOV：Camera3D 每帧读取 FreeGrapple 的 `cam_fov_boost` 叠加到画面 FOV

## 安全机制

| 机制 | 说明 |
|------|------|
| 防陷地 | 拉力方向 Y<0 时钳制为 0；切线投影保护 Y 分量；地面时清除向下速度；不禁用地面碰撞 |
| 防回甩 | 方案C 收绳模型：绳长持续缩短，超出时切线投影 |
| 发射后锁定 | 发射后车头不可转向 |
| 单次发射 | 每次飞行只能发射一次（但可接续新钩索） |
| 空气阻力 | 空中二次方阻力，防止无限加速 |
| 着地回 IDLE | FALLING/LAUNCHING 检测地面自动结束 |
| 超时保护 | `pull_max_time` 超时强制断绳 |
