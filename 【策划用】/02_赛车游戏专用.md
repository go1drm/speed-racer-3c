# 02 - 赛车游戏专用插件 / 工具

> 赛车游戏强相关的"省时利器"。本项目是球体驱动 + 自写漂移系统, 这里推荐的是**辅助工具**, 不是替代核心玩法。

## 赛道 / 路径设计 ⭐⭐⭐⭐⭐ 🟢

### Godot 内置 Path3D + PathFollow3D
- **位置**: 引擎自带, 直接添加节点
- **作用**: 创建 3D 曲线路径, 物体可沿路径移动
- **赛车游戏意义**:
  - 赛道**最佳路径**记录 (用于 AI 车手的 racing line)
  - **赛道边界检测** (是否偏离路线)
  - **复活点** (玩家翻车时找最近 PathFollow 投回赛道)
  - **关卡引导线** (新手指引箭头)
- **学习成本**: 低
- **建议先用这个**, 不够再换插件

### SmoothCurve3D (Path3D 增强)
- **GitHub**: https://github.com/derkork/godot-smooth-curve
- **作用**: 比 Path3D 更平滑的样条曲线, 支持切线编辑
- **赛车游戏意义**: 设计高速弯道时, Path3D 的折点会让最佳路径不平滑

### Godot Path 3D Tools
- **AssetLib**: 搜 "Path 3D Tools"
- **作用**: 在 Path3D 上沿路径**自动复制 mesh** (栏杆 / 路灯 / 广告牌)
- **赛车游戏意义**: 一条赛道做几百米, 手动放路灯要疯, 这个一键沿路径布

## 计时 / 圈数 / 排行榜 ⭐⭐⭐⭐ 🟢

### CheckpointSystem (Godot)
- **概念**: 没有现成插件, 自己写
- **怎么做**: 用 Area3D 做检查点, 记录穿越时间, 算圈速
- **本项目状态**: 还没做, 后期需求时再加

### Godot Timer (内置)
- 用 Timer 节点做圈速倒计时, 最佳圈记录

### LocalLeaderboard (本地排行榜)
- **概念**: 写到 `user://leaderboard.cfg`, 用 ConfigFile API
- **赛车游戏意义**: Demo 阶段不用做云排行榜, 本地存就够

### Steam Leaderboards (上线后)
- **GitHub**: https://github.com/GodotSteam/GodotSteam
- **作用**: 调用 Steam API 上传成绩到全球排行榜
- **赛车游戏意义**: 上 Steam 之后必装

## 重播系统 (Replay) ⭐⭐⭐ 🟡

### 自己实现 (推荐)
- 每帧记录: car position / rotation / velocity / drift state / steer / boost type
- 60Hz 录制, 一圈赛道 ~3MB 数据
- 回放: 时间轴上 lerp 播放
- **本项目**: 后期可以加, 现在不急

### Godot Replay (社区)
- **GitHub**: 搜 "godot-4 replay"
- 大部分还是 3.x, 自己写更靠谱

## AI 对手 / NPC 车手 ⭐⭐⭐ 🟡

### Path3D + PathFollow3D + 简单 PID 控制
- **概念**: NPC 车沿 Path3D 行驶, 速度由 PathFollow.progress 控制
- **赛车游戏意义**: 单机模式必备
- **难度**: 中, 主要是"超车 / 防撞 / 智能反应"逻辑要自己写

### Godot Steering Behaviors / GSAI
- **GitHub**: https://github.com/GDQuest/godot-steering-ai-framework
- **作用**: AI 转向行为框架 (避障, 跟随, 巡逻)
- **维护**: ⏸️ Godot 4 兼容性需确认
- **赛车游戏意义**: 实现"NPC 车互相超车"等行为

## 输入控制 ⭐⭐⭐⭐ 🟢

### Godot Input Helper
- **作用**: 简化 InputMap 管理, 自动检测设备类型 (键鼠 / 手柄 / 方向盘) 切换提示图标
- **赛车游戏意义**: HUD 上显示按键提示时, 检测玩家用的设备显示对应图标 (如玩家用手柄, 显示 ▢/△ 而不是 Q/W)

### Godot Steering Wheel Plugin (方向盘力反馈)
- **作用**: 支持 Logitech / Thrustmaster 力反馈
- **赛车游戏意义**: 漂移/撞墙时, 方向盘抖动/拉拽, 拟真感拉满
- **状态**: Godot 4 暂时没成熟方案, 大多需要走 GDExtension 调 SDL2

## 关卡设计辅助 ⭐⭐⭐⭐⭐ 🟢

### TerrainTool / HTerrain
- **GitHub**: https://github.com/Zylann/godot_heightmap_plugin
- **作用**: 地形编辑器, 用笔刷雕地形 + 多层贴图混合
- **赛车游戏意义**: 做开放地形赛道 (沙漠 / 雪山 / 山路), 比 Blender 效率高 5 倍
- **维护**: 🔥 (Godot 4 版本叫 hterrain)

### Scatter (场景资源散布)
- **GitHub**: https://github.com/HungryProton/scatter
- **AssetLib**: "Scatter"
- **作用**: 在指定区域 (Path/Polygon/Mesh) 内随机散布资源 (树木 / 石头 / 路标)
- **赛车游戏意义**: 赛道两边布树/草丛, 不用一个个手动放

### MeshGenerator / 路径挤出
- **概念**: 沿 Path3D 挤出 mesh, 自动生成赛道 mesh + 物理碰撞
- **GitHub**: 搜 "godot path mesh extrusion"
- **赛车游戏意义**: 想程序生成赛道时用 (如无尽赛道)
