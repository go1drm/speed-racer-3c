# 07 - 推荐插件总评分表

## 评分维度

- ⭐ **推荐度**: 1-5, 越多越值得装
- 📦 **维护**: 🔥活跃 / ⏸️稳定 / ⚠️弃坑风险
- 💡 **学习**: 🟢简单 / 🟡中等 / 🔴复杂
- 🎯 **赛车专属**: 🚗专为赛车 / 🎮通用游戏 / 📦工具

## ⚠️ 慎用 / 暂时别装

| 插件 | 原因 |
|---|---|
| 各种 VehicleBody3D 替代品 | 我们用球体驱动, 不需要 |
| Godot 3.x 专用插件 | Godot 4 不兼容 |
| 网络对战插件 (Nakama 等) | Demo 阶段没必要 |
| 老的 "AI 车手" 插件 | 大部分 Godot 4 没适配, 自己写更可控 |

## 整理总结

- **本项目代码核心 (反打/漂移/集气) 自己写**: 不依赖任何插件, 安全
- **美术/特效**: 用插件 + CC0 资源, 免费 + 商用 OK
- **基础设施 (物理/相机/音频)**: 选活跃维护的插件, 别用老古董
- **测试/调试**: 用社区成熟工具, 自己写测试反而费时间

## 我的建议执行顺序 (针对你这个项目)

```
[1 天] Bebas Neue 字体 + ambientCG 贴图 (基础美术升级)
   ↓
[1 周] Reactive Inspector + DebugDraw3D (调试效率翻倍)
   ↓
[2 周] 音效系统 Phase 1 (4 层引擎声 + 漂移尖叫)
   ↓
[1 月] Phantom Camera + Trail 3D (镜头 + 漂移痕迹)
   ↓
[2 月] HTerrain + Quaternius (做新赛道)
   ↓
[3 月] 完整音效包 + BGM
   ↓
[6 月] 上线前打磨 + Steam 集成
```

每个阶段做完跑一下 Demo, 录一段视频, 看是不是真的"游戏感"提升了 — 提升了再继续, 没提升说明这个阶段的工具不适合你的需求, 跳过。
