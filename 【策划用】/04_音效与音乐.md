# 04 - 音效与音乐

> 赛车游戏 70% 的爽感来自音效。引擎声 / 漂移声 / 撞击声不到位, 视觉再炫也假。

## Godot 4 音频系统基础 ⭐⭐⭐⭐⭐ 🟢

### 内置 AudioStreamPlayer3D + AudioBus
- 已经够强大
- **赛车游戏意义**:
  - 3D 空间感 (引擎声有方位)
  - AudioBus 分组 (Master / SFX / Music / UI 各自调音量)
  - Reverb / Compressor / Limiter 后处理

### AudioStreamPlayer3D 关键参数
- `unit_size`: 衰减距离基准
- `max_distance`: 听不见的距离
- `pitch_scale`: ⭐⭐⭐⭐⭐ 引擎声变速核心
- `doppler_tracking`: 多普勒效应 (车飞过去音调变低)

## 引擎声系统 ⭐⭐⭐⭐⭐ 🟢

### 推荐做法: 4-Layer 引擎声

参考实战经验, 做出真实引擎声需要 4 层叠加:

| 层 | 内容 | 触发条件 |
|---|---|---|
| 1 | 怠速 (Idle Loop) | 车不动, 油门松 |
| 2 | 中转速 (Mid RPM) | 行驶中, 油门 50%-80% |
| 3 | 高转速 (High RPM) | 高速, 油门 100% |
| 4 | 减速 (Decel) | 松油门高转速时的"放炮" 声 |

### 实现思路
```gdscript
# car.gd 里加
var rpm: float = current_speed / max_speed    # 0~1
$EngineLayer1.volume_db = lerp(0.0, -30.0, clamp(rpm * 2, 0, 1))     # 高速时弱
$EngineLayer2.volume_db = lerp(-30.0, 0.0, clamp(rpm * 2, 0, 1))     # 高速时强
$EngineLayer1.pitch_scale = lerp(0.8, 1.4, rpm)                       # 转速越高音调越高
```

### 工具: GodotEngineSoundPlugin (无现成插件)
- **概念**: 没有专门的, 自己用上面的 4-layer 思路
- **学习参考**: Unity FMOD 的 RaceCar 样例

## 物理触发音效 ⭐⭐⭐⭐ 🟢

### 漂移轮胎尖叫
- **数据源**: `drift_intensity` (0-1)
- **音效**: 持续 loop 的 tire_squeal.ogg
- **代码**: `volume_db = lerp(-80, -10, drift_intensity)`

### 撞击声
- **触发**: `wall_crashed` 信号 (我们已有)
- **强度**: 由 wall_hit_kickback 强度决定 pitch / volume
- **多样化**: 准备 5 个不同的 crash_*.ogg 随机播放

### 氮气声
- **触发**: `boost_triggered("nitro")` 信号
- **音效**: 起始 whoosh + 持续 turbine loop
- **结束**: 衰减 fade

### 加速带触发音
- **触发**: SpeedPad.gd `_on_body_entered` 时
- **音效**: 短促的 woooosh 音效

## 音乐 (BGM) ⭐⭐⭐ 🟡

### 风格选择
赛车游戏 BGM 风格:
- **Electronic** (Need for Speed 风): 高能 EDM
- **Rock / Metal** (Burnout 风): 重金属
- **Lo-Fi / Synthwave** (复古赛博风): 80年代风格
- **Orchestral** (F1 / Gran Turismo): 史诗

### 免费 BGM 来源
- **Pixabay Music**: https://pixabay.com/music/ (CC0 风格丰富)
- **Free Music Archive**: https://freemusicarchive.org/ (注意协议)
- **YouTube Audio Library**: 开 YouTube 创作者后台找
- **OpenGameArt**: https://opengameart.org/ (老 jam 风格多)

- "electronic action"
- "racing intense"
- "drift edm"

- ✅ Master / SFX / Music 3 个 AudioBus

## 一个隐藏建议

**音效是赛车游戏的爽感天花板**, 比视觉更重要。视觉再炫但听起来像玩具车, 玩家 5 分钟就会无感。反过来, 视觉一般但音效专业, 玩家会觉得"这游戏有质感"。

所以 Phase 1 不要拖, 越早做越好。
