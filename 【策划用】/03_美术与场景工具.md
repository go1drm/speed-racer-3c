# 03 - 美术与场景工具

> 让赛车游戏"看起来不像 Demo"的关键。

## Shader / 材质 ⭐⭐⭐⭐⭐ 🟢

### Godot 4 PBR 材质 (内置)
- 默认 StandardMaterial3D 已经够用
- **赛车游戏意义**: 车漆 / 金属 / 玻璃 都用它

### Car Paint Shader (车漆)
- **GitHub**: 搜 "godot 4 car paint shader"
- **作用**: 车漆专用 Shader (双层漆 + 金属粉 + Fresnel 反光 + 油漆颗粒感)
- **赛车游戏意义**: 默认 PBR 的车漆看起来塑料感强, 这个能做出"金属漆 / 珠光漆 / 哑光漆"
- **本项目状态**: 现在用的是 FBX 自带 StandardMaterial3D, 后期想做 4 套车漆变体时换

### GodotShaderLibrary
- **GitHub**: https://github.com/godotengine/godot-shader-library  
- **作用**: 100+ 现成 Shader (水/雪/玻璃/金属/卡通/全息)
- **赛车游戏意义**: 找雨水冲击地面 / 雪地车辙 等, 不用自己写

### Snapshot Shader Pack
- **GitHub**: 搜 "godot snapshot shader"
- **作用**: 简单到复杂的 Shader 合集
- **赛车游戏意义**: 大量"特效底子", 自己改一改改成你想要的

## 粒子特效 ⭐⭐⭐⭐⭐ 🟢

### Godot 4 GPUParticles3D (内置)
- 现代 GPU 粒子, 性能比 CPU 强 10x
- **赛车游戏意义**:
  - 漂移轮胎烟雾 ✅
  - 撞击火星 ✅
  - 氮气尾焰 ✅
  - 雨点 / 雪花 ✅

### Godot Particle Editor (社区版)
- **GitHub**: 搜 "godot particle editor plugin"
- **作用**: 可视化编辑 GPUParticles 参数, 不用进 Inspector 一项项调
- **赛车游戏意义**: 烟雾/火花调起来直观

### Trail 3D / 拖尾效果
- **GitHub**: https://github.com/OBKF/Godot-Trail-System
- **作用**: 3D 拖尾系统, 跟随节点产生平滑拖尾
- **赛车游戏意义**: ⭐⭐⭐⭐⭐
  - 漂移时**轮胎拖痕** (黑色印迹留在地面)
  - 氮气**尾焰光线**
  - 高速**速度线**
- **本项目**: 现在 DriftFX.gd 是粒子, 拖尾痕迹效果用这个会更好

## 后处理 (Post-Processing) ⭐⭐⭐⭐ 🟢

### Godot 4 内置 Environment 后处理
- 默认有: Bloom, SSAO, SSIL, SDFGI, FSR2, Glow
- **赛车游戏意义**:
  - **Motion Blur (动态模糊)**: 高速感的灵魂
  - **Chromatic Aberration**: 撞击/氮气时的色散
  - **Vignette**: 镜头四周变暗, 速度感

### CSG Post-Processing Volume
- **作用**: 局部后处理 (进入隧道时变暗, 出隧道时恢复)
- **赛车游戏意义**: 隧道 / 山洞 / 室内段落

### Godot Camera Effects
- **GitHub**: 搜 "godot 4 camera effects"
- **作用**: 屏幕震屏 / 模糊 / 色彩偏移合集
- **赛车游戏意义**: 撞墙震屏 (我们已经有 emit_signal("camera_shake_requested")), 但视觉效果可以更猛

### KameraVR / RenderingServer 屏幕扭曲
- **作用**: 速度感屏幕扭曲 (氮气时屏幕鱼眼 / 弯曲)
- **赛车游戏意义**: ⭐⭐⭐⭐⭐ 氮气视觉的灵魂, 没这个氮气感觉很弱

## 天空 / 光照 ⭐⭐⭐⭐ 🟡

### Time of Day (TOD)
- **GitHub**: https://github.com/jamie-pate/godot-procedural-skybox  
- **作用**: 程序化天空 + 太阳轨迹 + 昼夜循环
- **赛车游戏意义**: 想做日落赛道 / 夜间赛道时

### Godot Sky Customizer
- **AssetLib**: 搜 "Sky Customizer"
- **作用**: 调天空颜色 / 云层 / 雾
- **赛车游戏意义**: 不同赛道氛围切换

## 模型 / 动画 ⭐⭐⭐ 🟡

### Mixamo Animation Retargeter
- **作用**: 把 Mixamo 动画导入 Godot
- **赛车游戏意义**: 角色动画 (颁奖台 / 庆祝动作)
- **本项目**: 暂时不用 (没有人物角色)

### glTF 工具链
- **AssetLib**: "glTF Importer Plus"
- **作用**: 比默认 glTF 导入更可控
- **赛车游戏意义**: 从 Blender 导车模时

## UI / HUD ⭐⭐⭐⭐ 🟢

### Godot UI Animation Library
- **GitHub**: 搜 "godot ui anim"
- **作用**: 弹字 / 滑入 / 抖动等 UI 动画
- **赛车游戏意义**: 集气满弹字 / 排名变化动画

### Tween Plus / GodotTween
- **概念**: Godot 4 内置 Tween 已经强大
- **赛车游戏意义**: 数字滚动 / 进度条平滑 (HUD 集气槽)

### Godot Fonts (Pixel/赛车风格)
- **CC0**: https://www.dafont.com/  (筛选 Free for commercial use)
- **赛车游戏意义**: 速度数字用专业字体, 不要用默认黑体
- **推荐字体**:
  - Bebas Neue (高度浓缩, 速度感)
  - Orbitron (科幻赛博)
  - Speed Tribute (经典赛车)
