# 06 - 免费 / 免版权素材资源

> 商用 OK 的免费资源站, 让你的 Demo 看起来不像穷酸样。

## 协议速查

| 协议 | 含义 | 商用 |
|---|---|---|
| **CC0** / Public Domain | 完全无版权, 想干啥干啥 | ✅ 不用注明 |
| **CC-BY** | 需注明作者 | ✅ 必须注明 |
| **CC-BY-SA** | 注明 + 衍生品同协议 | ✅ 但有限制 |
| **CC-BY-NC** | 仅非商用 | ❌ 别用 |
| **GPL/AGPL** | 衍生品必须开源 | ⚠️ 项目代码会被传染 |
| **MIT/Apache 2.0** | 商业友好 | ✅ |

赛车 Demo 起步阶段优先 **CC0** 资源, 没顾虑。

## 贴图 / 材质 ⭐⭐⭐⭐⭐ 🟢

### ambientCG (推荐 ⭐⭐⭐⭐⭐)
- **链接**: https://ambientcg.com/
- **协议**: CC0
- **赛车游戏可用**: PBR 材质 (沥青 / 混凝土 / 草地 / 沙子)
- **特点**: 每个材质带完整 PBR (Albedo / Normal / Roughness / AO / Height)

- **链接**: https://polyhaven.com/
- **协议**: CC0
- **赛车游戏可用**:

  - **HDRIs**: 天空盒/环境光 (赛道氛围灵魂)

- **特点**: 比 ambientCG 质量更高, 但量没那么多
