## 安装方式速查

### 方式 1: AssetLib (Godot 内置)
1. 打开 Godot 编辑器
2. 顶部菜单 → AssetLib (或资源库)
3. 搜索插件名 → 下载 → 安装到项目
4. Project → Project Settings → Plugins → 启用

### 方式 2: GitHub 直装
1. 打开仓库 README
2. 把 `addons/<plugin_name>/` 拷贝到项目根目录的 `addons/` 下
3. Project Settings → Plugins → 启用

### 方式 3: gd-plug (推荐, 像 Vim 装插件)
```bash
# 一次性写一份插件清单, 团队共享
# https://github.com/imjp94/gd-plug
```

## 我的推荐 Top 5 (赛车游戏版)

按"装上立刻爽"排序:

1. ⭐⭐⭐⭐⭐ **GodotJoltPhysics** — 比 Godot 默认物理稳定 5 倍, 赛车游戏必装
2. ⭐⭐⭐⭐⭐ **Path3D Tools / SmoothCurve3D** — 赛道路径设计核心
3. ⭐⭐⭐⭐⭐ **Debug Menu / Reactive Inspector** — 调参不死人
4. ⭐⭐⭐⭐ **CarPaintMaterial / Shader 合集** — 让车看起来不像塑料
5. ⭐⭐⭐⭐ **Godot Trail 3D / TrailFX** — 漂移烟雾痕迹

详见各分类文档。

## 分级标识

文档里每个插件都标了:

- 🟢 **推荐**: 装就完事
- 🟡 **可选**: 看具体需求
- 🔴 **慎用**: 有坑/老旧, 仅在没替代品时考虑
- ⭐ 数量 = 综合推荐度 (1-5 颗星)
- 📦 维护活跃度: 🔥(频繁更新) / ⏸️(稳定不动) / ⚠️(看起来弃坑)

## 给我自己的 6 句忠告

1. **不要装太多插件**: 每个插件都是依赖, 项目越大越难拆
2. **优先用 Godot 原生节点**: 比如 Path3D 已经够用, 不一定要装 SmoothCurve3D
3. **AssetLib 上很多老插件是 Godot 3.x**, Godot 4 不兼容. 装之前看 README 标注的版本号
4. **插件版本要和 Godot 版本对齐**: 4.0/4.1/4.2/4.3/4.6 之间也可能有 API 差异
5. **核心玩法代码自己写**: 反打/漂移/集气这种"游戏灵魂"不要依赖第三方, 万一作者弃坑你哭都没地方哭
6. **特效插件好看就行, 别迷信"性能优化插件"**: 大部分性能优化插件解决的是项目层面的架构问题, 不是它装上就能修
