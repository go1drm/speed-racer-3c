# 01 - 必备插件 (通用基建型)

> 任何 Godot 4 项目都建议装的"基础设施"插件。

## 物理引擎替代 ⭐⭐⭐⭐⭐ 🟢

### Godot Jolt Physics
- **GitHub**: https://github.com/godot-jolt/godot-jolt
- **AssetLib**: 直接搜 "Jolt Physics"
- **维护**: 🔥 活跃
- **作用**: 替换 Godot 默认 Bullet/Godot Physics, 用 Jolt 引擎 (Horizon Zero Dawn 用的物理)
- **赛车游戏意义**: ⭐⭐⭐⭐⭐
  - 默认物理在高速 (>100 km/h) RigidBody3D 容易抖动/穿透
  - Jolt 处理 contact 更稳定, 球体驱动赛车不会鬼畜
  - 性能比默认快 30%-50%
- **安装**: AssetLib 搜索安装, Project Settings → Physics → 3D → Physics Engine = "JoltPhysics3D" 或 "Jolt 3D"
- **踩坑**: 切换后要重启 Godot; 有些 PhysicsBody3D 默认参数不一样, 要重新调
- **本项目兼容性**: ⚠️ 我们用了球体驱动 + 自定义 _integrate_forces, 切之前先备份做对比

## 编辑器增强 ⭐⭐⭐⭐⭐ 🟢

### Editor Console (内置, 推荐打开)
- **位置**: 默认就有, 在编辑器底部
- **作用**: 看 print/push_warning 输出
- **赛车游戏意义**: 调反打/集气/碰撞数值时离不开
- **配合**: 我们项目里大量 `[Car]` `[Tuner]` `[SpeedPad]` print, 都从这看

### Godot Debug Console (插件)
- **GitHub**: https://github.com/jitspoe/godot-console
- **维护**: ⏸️ 稳定
- **作用**: 游戏内 ` 键弹出命令行, 可以执行 GDScript 命令
- **赛车游戏意义**: 测试时可直接 `set_speed 100` / `teleport(0, 5, 0)` / `enable_speed_pad false`
- **学习成本**: 中, 要自己注册命令

### Reactive Inspector
- **GitHub**: https://github.com/cangiabaresi/godot-reactive-inspector  
- **作用**: 让 @export 变量在游戏运行时实时改, 不用停止再启动
- **赛车游戏意义**: 调反打角速度 / 加速带推力时, 跑着改, 立马看效果
- **替代**: 我们已经有 Tuner UI, 但 Reactive Inspector 更通用

## 输入处理 ⭐⭐⭐⭐ 🟢

### Phantom Camera (摄像机系统)
- **GitHub**: https://github.com/ramokz/phantom-camera
- **AssetLib**: 搜 "Phantom Camera"
- **维护**: 🔥 活跃
- **作用**: 给 Godot 加一个类似 Cinemachine (Unity) 的相机系统
- **赛车游戏意义**: ⭐⭐⭐⭐⭐
  - 内置"跟随车辆 + 速度时拉远 + 漂移时偏移"模板
  - 能配置 dead zone / damping / 多相机切换 (车内视角 / 跟随 / 重播)
  - 如果你想做"漂移瞬间镜头猛甩"这种戏剧化运镜, 这个是首选
- **学习成本**: 中, 文档完整
- **本项目**: 现在用的是 `Camera3D.gd` 自己写的简单跟随, 后期想升级镜头戏剧感时换它

### Godot Steam Input (手柄/方向盘支持)
- **GitHub**: https://github.com/GodotSteam/GodotSteam
- **作用**: 通过 Steam Input API 适配各种手柄/方向盘 (Logitech G29, Thrustmaster T300 等)
- **赛车游戏意义**: 卖到 Steam 必备, 否则方向盘玩家骂你
- **替代**: 如果只支持键盘 + Xbox 手柄, Godot 原生 InputMap 够用

## 资源管理 ⭐⭐⭐ 🟡

### gd-plug (插件管理器)
- **GitHub**: https://github.com/imjp94/gd-plug
- **作用**: 像 vim-plug 一样, 写一份 `plug.gd` 配置, 自动从 GitHub 下载/更新所有插件
- **赛车游戏意义**: 团队协作时, 大家保持插件版本一致

### Resource Loader Plus (热重载)
- **作用**: 修改资源文件时自动重新加载, 不用重启 Godot
- **赛车游戏意义**: 改美术 / 调材质 / 改 Curve 资源时省事

## 不要装 (慎用) 🔴

| 插件 | 原因 |
|---|---|
| Godot 3.x 时代的所有"GUI 主题包" | Godot 4 主题系统改了, 旧的全坏 |
| 某些"AI 一键生成"类 | 中文文档极少, 出问题没人帮你看 |
| 老的 "Vehicle System" 类 | 大部分基于 VehicleBody3D, 你的项目是球体驱动, 用不上 |
| `WaterShader 4.x` 之前版本 | 新版本 Godot 4.3+ 有内置 |

---

## 安装顺序建议

新项目装的时候, 按这个顺序安装, 避免冲突:

1. Godot Jolt (物理底层)
2. Reactive Inspector / Debug Console (调试基建)
3. Phantom Camera (相机)
4. 然后按需求装赛车专用的 (见 02 文档)

每装一个就跑一下游戏, 确认没崩再装下一个。
